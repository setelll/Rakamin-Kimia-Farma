# Rakamin-Kimia-Farma

Ini adalah projek akhir dari Project-Based Internship saya sebagai Big Data Analyst di Kimia Farma (lewat program Rakamin Academy). Tujuan projek ini adalah untuk menganalisis kinerja bisnis Kimia Farma dari tahun 2020 hingga 2023 menggunakan Google BigQuery dan Google Looker Studio

Tugas ini mencakup: mengimpor 4 dataset ke BigQuery, menggabungkan dan mengolah data menjadi satu tabel analisa, dan membangun dashboard visualisasi kinerja bisnis
